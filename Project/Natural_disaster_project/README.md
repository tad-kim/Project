# 자연재난 피해 통계 EDA 프로젝트 (2019~2023)

## 📌 프로젝트 개요
- 자연재해로 인한 피해 데이터를 기반으로 전국적 피해 규모와 유형을 분석
- 재난 대응 전략 수립에 도움이 될 인사이트 도출

## 🗂️ 데이터 정보
- 출처: 행정안전부 국가재난정보센터 (공공데이터포털)
- 파일: `자연재난상황통계.xlsx`
- 기간: 2019년 ~ 2023년

## 🔍 주요 분석 내용
- 전국적으로 피해 규모가 가장 큰 재난유형
- 연도별 피해 패턴 및 트렌드
- 피해 유형별 상세 구분
- 시각화를 통한 주요 원인 파악

## 🛠️ 사용 기술
- Python (Pandas, Matplotlib, SQLite3)
- VS Code, GitHub
- Chat GPT

## 📊 결과 예시
- 피해 규모 Top 5: 공공시설, 건물, 농경지 등
- 피해가 가장 컸던 해: 2020년
