 **지방소멸 시대의 의료공백 분석**
─ 전국 의료기관 표준데이터 기반 EDA 프로젝트 ─


1. 프로젝트 개요

본 프로젝트는 보건복지부 전국의료기관표준데이터를 기반으로,

 ● 전국 병원의 영업 상태(정상/폐업/휴업 등) 분포를 확인하고

 ● 폐업 병원의 진료과목 특성을 분석하며

 ● 특정 진료과목(산부인과)의 지역별 분포 유무를 통해

지방 인구소멸 현상과 의료 공백 간의 연관성을 탐색하는 것을 목표로 합니다.
지역별 의료공급 편차를 시각적으로 파악하고, 정책적 시사점을 도출합니다.

2. 분석 목적

 ● 전국 의료기관의 영업현황을 지역 단위로 정리

 ● 폐업 병원의 진료과목 분포를 분석하여 구조적 위험요인 파악

 ● 정상 운영 중인 병원들 중 '산부인과'가 없는 시군구 식별

 ● 시도/시군구/권역별 진료공백 시각화로 의료 접근성 불균형 조망

 ● 이를 바탕으로 의료공백이 심각한 지역 = 인구소멸 가능성 지역이라는
   인사이트 제시

3. 주요 분석 내용

 ● 전국 의료기관의 영업상태 분포 시각화 (Pie Chart)

 ● 시도별 병원 영업상태 비교 (Stacked Bar Chart)

 ● 권역(도)별 시군구 폐업 병원 수 비교

 ● 폐업 병원의 주요 진료과목 분해 및 Top 15 시각화

 ● 정상 병원의 진료과목 다층 분해 및 지역별 Pivot Table 구성

 ● '산부인과'가 없는 시군구 히트맵 분석

 ● 경기·강원·충청·전라·경상 권역별 산부인과 병원 수 히트맵

4. 기대 효과 및 활용 방향

 ● 보건의료 정책 수립 시 진료과목별 지역공백 보완에 대한 데이터 기반
   의사결정 지원

 ● 산부인과 부재 지역을 인구소멸 위험 지역으로 간주할 수 있는 정성적
   지표 확보

 ● 출산율 저하 및 의료인력 재배치 등 향후 정책 방향 설정에 활용 가능

 ● 공공기관, 지자체, 보건복지부 등에서 정책 우선순위 도출 근거자료로
   활용 가능
