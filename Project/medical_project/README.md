    1. 프로젝트 개요: 지방소멸 시대의 의료공백 분석
본 프로젝트는 전국 의료기관 표준 데이터를 활용하여 의료기관의 영업 상태, 진료과목 분포, 그리고 **특정 진료과목(산부인과)**의 지역별 분포를 분석함으로써,
지방 인구소멸과 의료공백의 연관성을 시각적으로 추론하고자 합니다.

     2. 분석 목적
**전국 의료기관의 영업상태 분포(정상, 폐업, 휴업 등)**를 파악

폐업 병원의 진료과목 유형 분석을 통해 구조적 의료서비스 변화 탐색

정상 영업 중인 병원 중 '산부인과' 진료과목 부재 지역 탐색

이를 통해 의료서비스 취약 지역 = 인구 소멸 우려 지역이라는 정성적 인사이트 도출

     3. 주요 분석 내용
전국 의료기관의 영업상태(정상/폐업/휴업 등) 파악

광역지자체(시도)별 병원 폐업 수 시각화

폐업 병원의 주요 진료과목 분해 및 빈도 분석

정상 운영 중 병원의 진료과목 다층 분해

특정 진료과목('산부인과')이 없는 지역 시군구 도출

권역별(경기/강원/충청/전라/경상) 산부인과 유무 히트맵 시각화

     4. 기대 효과
보건의료 정책 수립 시 진료과목별 지역공백을 반영한 보완정책 설계

산부인과와 같은 기초 의료서비스 부재 지역을 기반으로 한 지방 인구소멸 신호 탐지

향후 고령화, 출산율 저하에 따른 의료자원 재배분 전략에 데이터 기반 근거 제공
